# Manual Setup Checklist

These are the items the user may need to do directly in the Codex app UI.

## Do Now

### 1. Enable Browser Use

Why:

- Codex can open the local app, click buttons, inspect the rendered page, and verify layout issues.

What to do:

- Open Codex Settings.
- Go to Browser use.
- Confirm the Browser plugin is enabled.
- Allow local URLs such as `http://localhost:3000`, `http://localhost:5173`, or file-backed previews when Codex asks.

### 2. Turn On Notifications

Why:

- Useful while Codex is installing, running checks, or building the app.

What to do:

- Open Codex Settings.
- Enable completion notifications.

### 3. Set File Opener

Why:

- Clicking files from Codex should open in your preferred editor.

What to do:

- Open Codex Settings.
- Choose VS Code or your preferred editor for opening files.

### 4. Enable Memories If Available

Why:

- Helps Codex remember that you are new to coding, prefer Korean explanations, and are preparing for AICE Basic.

What to do:

- Open Codex Settings.
- Enable Memories if the option is available in your account or workspace.

## Optional Later

### Sites

Use later when the local app is ready to publish.

Do not deploy the first rough draft unless you intentionally want a live version.

### Spreadsheets

Use when the quiz bank becomes large or when you want to manage questions in a table.

### Documents

Use when you want printable notes or a study summary document.

### GitHub

Use later if you want cloud backup, version history, or pull-request style review.

## Not Needed Yet

- Login setup
- Database setup
- Payment setup
- Slack or Gmail integration
- Chrome extension for signed-in browser work
- AI chatbot API key

## Current Recommendation

Stay local and simple until the app has:

- A dashboard
- Study cards
- Quiz mode
- Mock exam mode
- Progress saved in `localStorage`

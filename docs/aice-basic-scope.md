# AICE Basic Scope

Last checked: 2026-06-09

Primary source: https://aice.study/info/aice/basic

## Exam Shape

Based on the official AICE Basic page checked during project setup:

- Level: Basic
- Target: AI beginners, non-programmers, no-code AI learners
- Format: practical evaluation
- Tool: AIDU
- Data type: tabular data
- Questions: 15
- Time: 60 minutes
- Passing score: 80 or higher out of 100
- Validity period: permanent

## Core Study Areas

### Exploratory Data Analysis

Practice understanding the data before modeling.

Study items:

- Basic data inspection
- Data types
- Distributions
- Visualizations
- Correlations
- Outliers
- Data quality

### Data Preprocessing

Practice improving raw data before modeling.

Study items:

- Missing value handling
- Outlier handling
- Encoding
- Normalization or scaling
- Choosing appropriate preprocessing by data type

### AI Modeling

Practice choosing and understanding model training.

Study items:

- Machine learning model training
- Decision tree
- Random forest
- KNN
- Basic deep learning model training concepts
- Difference between training and evaluation

### Model Performance Evaluation

Practice interpreting the result after modeling.

Study items:

- Performance metrics
- Feature importance
- Model comparison
- Performance improvement simulation
- Understanding whether a model is useful for the problem

## Study App Interpretation

The app should train exam thinking rather than recreate the official exam.

For example:

- "What should I check first in this dataset?"
- "Which preprocessing step is appropriate?"
- "Why would normalization matter here?"
- "What does feature importance tell me?"
- "If performance is low, what should I try next?"

## Important Note

The official AICE pages may update exam details. Before scheduling or taking the exam, re-check the official AICE website directly.

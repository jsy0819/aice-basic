# AICE Basic 서비스 검토

작성일: 2026-06-10

## 현재 상태

현재 앱은 혼자 휴대폰으로 짧게 공부하기 위한 정적 웹앱으로는 충분히 가벼운 구조입니다.

- 설치 없이 `app/index.html` 실행
- GitHub Pages 배포 가능
- 로그인, 백엔드, DB 없음
- 브라우저 `localStorage` 저장
- 기본 문제 80개
- 직접 검수한 문제 추가 가능
- 빠른 퀴즈, 15문항 모의고사, 개념 카드, AIDU 체크리스트 포함

## 부족하거나 다음에 추가하면 좋은 기능

우선순위가 높은 개선은 아래 순서입니다.

1. 데이터 백업/복원
   - GitHub Pages에 배포하면 휴대폰 브라우저의 `localStorage`에 저장됩니다.
   - 휴대폰을 바꾸거나 브라우저 데이터를 지우면 기록이 사라질 수 있습니다.
   - 다음 단계로 `내보내기 JSON`, `가져오기 JSON` 기능을 추가하는 것이 좋습니다.

2. 문제 일괄 등록
   - 현재는 문제를 하나씩 입력합니다.
   - 검수한 문제가 많아지면 CSV/JSON으로 여러 문제를 한 번에 가져오는 기능이 필요합니다.

3. 오답 노트 강화
   - 지금은 틀린 문제를 복습 목록에 넣습니다.
   - 다음 단계로 `왜 틀렸는지`, `다시 볼 날짜`, `내 메모`를 붙이면 학습 효과가 좋아집니다.

4. 모바일 홈 화면 설치
   - 자주 쓴다면 PWA 설정을 추가해 휴대폰 홈 화면에 앱처럼 설치할 수 있게 만들 수 있습니다.
   - 단, 지금 단계에서는 GitHub Pages 배포 후 실제 사용감부터 확인하는 편이 좋습니다.

5. 문제 품질 관리
   - 중복 문제 감지
   - 출처별 필터
   - 검수일 기록
   - 정답/해설 누락 확인
   - 난이도 분포 확인

## 검증된 문제 수를 늘리는 방법

검증된 문제를 늘릴 수는 있지만, 공식 기출이나 유료 자료를 무단으로 복사해서 넣으면 안 됩니다.

현실적인 방법은 세 가지입니다.

1. 공식 공개 샘플이 있으면 직접 등록
   - 공식적으로 공개된 샘플 문제만 사용합니다.
   - 출처 메모에 공식 페이지명이나 자료명을 적습니다.

2. 사용 권한이 있는 교재/수업 자료를 직접 등록
   - 개인 학습용으로 사용 가능한 범위인지 확인합니다.
   - 앱의 `내 검수 문제 추가` 기능으로 직접 입력합니다.

3. 공식 범위 기반 자체 제작 문제를 더 만들기
   - 이 경우 `공식 기출`이 아니라 `범위 기반 자체 제작`으로 표시해야 합니다.
   - 현재 기본 80문항은 이 방식에 가깝습니다.

## 추천 다음 단계

1. GitHub Pages로 배포합니다.
2. 휴대폰에서 실제로 2-3일 써봅니다.
3. 불편한 점을 확인한 뒤 `백업/복원`과 `문제 일괄 등록`을 먼저 추가합니다.
4. 검증 자료가 생기면 문제 관리 화면에서 직접 등록합니다.
